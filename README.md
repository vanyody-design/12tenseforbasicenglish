# 12tenseforbasicenglish

**Tense Lab** — โปรแกรมฝึกไวยากรณ์อังกฤษครบทั้ง 12 Tenses สำหรับคนไทยที่อยากใช้ภาษาอังกฤษให้ถูกต้อง

เปิดใช้งานได้ทันทีโดยดับเบิลคลิก `index.html` ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต ความคืบหน้าเก็บไว้ในเครื่องผู้เรียนเอง

---

## เนื้อหาที่สอน

**12 Tenses ครบ** — Present / Past / Future × Simple / Continuous / Perfect / Perfect Continuous

| ส่วนประกอบ | รายละเอียด |
|---|---|
| การ์ดโครงสร้าง | แยก บอกเล่า / ปฏิเสธ / คำถาม ชัดเจน แต่ละรูปมีสูตร `S + V` พร้อมประโยคจริงและคำแปลไทยในการ์ดเดียวกัน |
| Timeline ภาพ | เห็นว่า tense นี้อยู่ตรงไหนบนเส้นเวลา และมีแถบ **เปรียบเทียบกับ tense ที่สับสนกันบ่อย** วางบนแกนเวลาเดียวกัน 21 คู่ |
| คำบอกเวลา | มีหน้าค้นย้อนกลับจาก *คำ → tense* 27 รายการ พร้อมเน้นคู่ที่สลับกันบ่อย เช่น `since` ↔ `for`, `by` ↔ `until` |
| ข้อผิดพลาดที่พบบ่อย | รวบรวมจุดที่คนไทยพลาดประจำในแต่ละ tense เช่น ลืมเติม s/es, ลืม been, ใช้ V2 แทน V3 |

## กติกาการฝึก

| กติกา | รายละเอียด |
|---|---|
| 1 รอบ = 10 ข้อ | ผ่านที่ 8/10 (80%) — รอบทบทวนที่มีไม่ถึง 10 ข้อ ใช้เกณฑ์ 80% ของจำนวนข้อจริง |
| หัวใจ 3 ดวง | **โหมดท้าทายเท่านั้น** ผิดหรือหมดเวลาเสีย 1 ดวง ผิดครบ 3 = จบรอบ · โหมดฝึกซ้อมและโหมดทบทวนผิดได้ไม่จำกัด |
| จับเวลา 30 วินาที/ข้อ | ใช้ในโหมดท้าทาย ปิดได้ในหน้าตั้งค่า |
| คอมโบ | ถูกติดกัน 3 ข้อ ได้ ×1.5 · ถูกติดกัน 5 ข้อ ได้ ×2 |
| คำใบ้ | กดได้ 1 ครั้งต่อข้อ แต่ได้ XP ครึ่งเดียวและคอมโบรีเซ็ต |
| ดาวความเชี่ยวชาญ | ผ่าน 3 รอบในหนึ่ง tense ถือว่าเชี่ยวชาญ |
| คลังทบทวน | ข้อที่ตอบผิดเข้าคลังอัตโนมัติ ต้องตอบถูกอีก 2 ครั้งจึงหลุดออก |

## รูปแบบข้อสอบ 6 แบบ

เลือกคำตอบ · เติมคำ · แปลงประโยค (บอกเล่า → ปฏิเสธ/คำถาม) · ระบุ Tense · หาที่ผิด · เรียงประโยค

โจทย์ทุกข้อสุ่มสร้างใหม่จากคลังประธาน 12 แบบ × กริยา 29 คำ × 6 รูปแบบ จึงจำคำตอบไม่ได้ ต้องเข้าใจจริงเท่านั้น ตัวเลือกลวงก็ตั้งใจสร้างจากรูปที่คนไทยมักตอบผิด ไม่ใช่สุ่มมั่ว

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บและแถบเมนู |
| `styles.css` | ธีมมินิมอล รองรับโหมดสว่าง/มืด/ตามระบบ และจอมือถือ |
| `data.js` | ข้อมูลไวยากรณ์ 12 tenses, คลังประธาน, คลังคำกริยา, ตารางคำบอกเวลา |
| `engine.js` | ตัวสร้างโจทย์และตรวจคำตอบ |
| `app.js` | ตรรกะแอป หน้าจอ และระบบความคืบหน้า |

ไม่มี dependency ภายนอก ไม่มี build step เป็น HTML/CSS/JavaScript ล้วน

## การใช้งาน

```
ดับเบิลคลิก index.html
```

หรือถ้าต้องการเปิดผ่าน local server:

```bash
npx serve .
```

ความคืบหน้าทั้งหมด (XP, ดาว, สถิติ, คลังทบทวน) เก็บใน `localStorage` ของเบราว์เซอร์ ล้างได้จากหน้าตั้งค่าในโปรแกรม
